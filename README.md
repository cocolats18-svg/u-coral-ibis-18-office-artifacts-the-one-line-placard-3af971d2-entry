A museum placard for the humble office stapler, recast as a ritual object of a lost civilisation: an instrument of the Rite of Binding, in which two sheets were joined irrevocably before witnesses — and recovered, centuries later, still loaded.

## The entry

> Ritual stapler, c. 2019. Pressed steel and spring. Used in the Rite of Binding, joining two sheets irrevocably before witnesses. Found still loaded. Gift of Accounts.

## How it works

Run `node main.ts` (Node 22+). It writes the single placard line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with a length gate that throws unless the line is 1–180 characters.
